# Security reporting

ShenSec handles credentials and target-controlled response data. Credential disclosure, unsafe redirect handling, report injection, and baseline bypasses are security-sensitive bugs.

Use GitHub private vulnerability reporting if it is enabled for this repository. Otherwise, open a minimal issue requesting a private reporting channel without publishing exploit details, credentials, or affected private target data. Do not include a production token, Cookie, workspace database, or unredacted report in a public issue.

Provide the source version, affected component, a local reproduction, and expected versus observed behavior. See `docs/limitations.md` for documented scope and `docs/authentication.md` for credential handling boundaries. This source beta does not provide a formal support SLA.
